# Introduction

This package can be used to create algorithms (algos) for your Laravel
application.

:::tip

Let your AI agent do the hard parts. This package ships a [Laravel Boost](https://laravel.com/docs/boost) skill, `algos-development`, that teaches your agent how to install, configure and use Laravel Algos. Install Boost and select the skill when prompted:

```bash
composer require laravel/boost --dev
php artisan boost:install
```

Already using Boost? Run `php artisan boost:update --discover` to pick up the skill. Then just ask, for example: *"Create an algo that builds a personal feed of five posts for the current user."*

:::

Continue to [Installation](./installation.md) to get started.
